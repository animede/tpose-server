Tポーズ4ビュー: 1枚の画像から3D化用のTポーズ立ち絵を生成

両腕を水平に広げたTポーズ(手のひらを正面へ)の正面・背面・左前45度・右前45度を生成します。 image-3d のマルチビュー入力(Hunyuan3D-2mv)と rig-service の自動リグ/VRM化(Tポーズ前提)向け。 正面を最初に生成し、他のビューはその正面画像を参照して連鎖生成します(前後の造形を揃えるため)。 image-3d へ渡すのは正面・背面の2枚にしてください(45度ビューは参考出力で、 2mv の left/right スロットへ入れるとカメラ事前分布を誤らせます。Tポーズの真横90度ビューは 手前の腕がカメラを向いて破綻するため提供しません)。 入力は全身でも胸像でも可(写っていない部分はモデルが創作します)。

ポーズモード

両腕を肩の高さで水平に広げたTポーズに変換します。

生成するビュー(チェックしたものだけ生成)

爪: 既定の「爪なし」では、後足の指の分離が保たれるように入力画像から毛色を 自動推定して色名をプロンプトへ入れます(相対表現では効かず具体的な色名が必要、という 実測に基づく)。
被写体タイプ: リアルな人形で「背面が動物になる」「手に肉球が付く」場合は 「人物・リアルな人形」を選んでください(自動は毛皮/肉球の語を一切使わない 中立プロンプトになります)。ぬいぐるみで毛皮・肉球をはっきり出したいときは 「動物・ぬいぐるみ」を選びます。
肉球: auto=入力画像の色を踏襲 / none=言及しない / 色名(例 pink)を書くとその色の肉球を描きます(色を書くと自動判定は動物になります)。

しっぽ形状は正面画像からは推定できません。未指定だとビューごとに別の形状が 創作されます(実測で ポンポン/なし/長い尻尾 にばらけました)。入力画像に しっぽが写っていない場合は必ず指定してください。参照画像で指定することもできますが、 顔や毛色まで参照画像側へ引きずられるため非推奨です。

脚が長くなる場合はここを指定してください。ポーズを変える際に モデルが体型を人型寄りにドリフトさせることがあり(肩ライン比の実測で 0.45→0.37まで伸びた)、体型を言語化するのが唯一効いた対処です (ぬいぐるみ・デフォルメ体型では指定推奨)。

前開きのベスト・カーディガン等で「背中にも前開きが描かれる」場合はここを 指定してください。既定では正面の見え方がそのまま背面に複製され、 背中の隙間からインナーが見えてしまいます(実測: 背中中央のインナー露出 51〜80%)。丈・範囲まで書くこと — 「背中を一枚で覆う」とだけ書くと衣装が伸びてワンピース化しました(実測)。 丈まで書いた例では 8〜13%(裾から見える正当な分)まで下がり、目視でも正解でした。

しっぽ参照画像(非推奨・実験用)

入力しておくと、各ビューの生成直後に同じ指示で自動的に色調整のEditが走ります (正面は調整後の画像を後続ビューの参照に使うので色が揃います)。生成回数が2倍に なり、強い指示は毛色や造形も動かします。生成後に何度でも試したい場合は 右側の「生成後の編集」を使ってください。

「高精度・髪対応」は髪束の隙間や毛先の半透明を保つ2048pxマッティングです (初回は約444MBのモデル取得が必要)。白背景版はそのまま残るので、 切り抜きが不自然なときは白背景版を使えます。image-3d は自前で背景除去するため 必須ではありません。

生成後の編集(何度でも適用できます)

対象ビュー(チェックしたものだけ編集)

Real-ESRGAN(x2)で拡大します。拡散モデルでの再生成ではないので内容は 変わりません(髪型・衣装がドリフトしない)。1枚あたり約2秒。 1024版はそのまま残り、<ビュー>_2048.png が追加されます (透過版があるビューは2048で切り抜きを作り直します)。ZIPにも含まれます。 元画像を編集すると、古い2048版は自動で破棄されます。

元画像も参照する: 入力画像を2枚目の参照として渡し、 「元の髪型に戻す」等で元の見た目を参照させます。ただし 元画像のポーズ・背景まで引き戻す事故があります (実測: 3seed中1つでTポーズが崩れて自然な立ち姿になり、別のseedでは背景が 市松模様になりました)。既定OFF、必要なときだけONにしてください。

色調整だけでなく汎用の修正に使えます(「帽子を外す」等)。 4枚のうち一部だけ直したいときは「対象ビュー」で選んで「選択したビューに適用」 (各タイルの「このビューを編集」でも1枚だけ適用できます)。編集は1世代分だけ元に戻せます。 強い指示は毛色や造形も動かします(実測: 暖色化の指示で毛色が黄褐色へ寄り爪が復活)。 背景透過版があるビューは編集後に作り直します。

透過画像の白残りを修正

髪の隙間など残った白をクリックすると、連続する近似色だけを透明化します。

赤い印が手動指定点です。白目や服の反射ではなく、透明にしたい白領域の内側をクリックしてください。
